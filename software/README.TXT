This folder contains Microtronic programs from the Microtronic Manual
Vol. 1 and Vol. 2 and from the book "Computer Games" (2094).

The programs were originally retrieved from the PDFs with an OCR
program. In October 2026 every one of them was verified and corrected
by Claude Code (Opus 5.5). Each was checked, instruction by
instruction, against the printed listings in the scanned manuals. The
letters-for-digits slips (O for 0, I for 1) were normalised and seven
genuine errors were corrected (in 17+4, BLOCKADE, NUMGUESS, PRIMES,
RESISTOR, SINUS and TITATO). Each file names the manual page it was
verified against. In two places (SINUS address 55, TITATO address 23)
the manual itself prints a code that contradicts its own mnemonic
column; the files follow the mnemonic, and say so in a comment.

HANOI, HAL9000, HELLO and PRIMES-ENUM are not from the manuals.
